Wingman Player and the YouTube Video Player skill now ship together, in one release with one version. The skill tells you when a new version is out and installs it when you say "update the YouTube skill". Download youtube_video_player-v1.0.0.zip for the skill and Wingman-Player-Setup.msi for the player. The skill now uses Wingman's v3 skill API, so it loads on current Wingman AI (tested on 3.2.12).
